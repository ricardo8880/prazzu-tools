# Candidatos a Core

O projeto mantém no Core apenas capacidades compartilhadas por módulos atuais.

## Capacidades compartilhadas atuais

- dinheiro, porcentagens e arredondamento;
- datas, competência e regras versionadas;
- histórico e persistência;
- exportação PDF/planilhas;
- imports tabulares;
- Analytics, SEO, acesso, feedback e integrações;
- regras trabalhistas compartilhadas quando usadas por mais de uma ferramenta;
- regra mensal de imposto de renda usada pelos módulos trabalhistas atuais.

## Diretriz

Não promover lógica específica de uma única ferramenta ao Core. Só centralizar quando existir reutilização real e equivalente entre módulos ativos.
