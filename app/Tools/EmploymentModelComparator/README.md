# Employment Model Comparator

## Descrição
Compares user-entered economics for W-2 employment and independent-contractor/self-employed arrangements.

## Funcionalidades
Side-by-side financial comparison. Plus features are declared in the module manifest and protected by central access rules.

## Experiência Essencial
