# Backup Withholding Calculator

## Descrição
Estimates U.S. federal backup withholding and user-entered state/other withholding on reportable payments.

## Funcionalidades
Single-payment backup-withholding estimate. Plus adds export and authenticated history.

## Experiência Essencial
Single-payment backup-withholding estimate.

## Prazzu Plus
Plus adds export and authenticated history.

## Regras
Federal backup withholding uses the current 24% rate when the user indicates it applies; state rules are user-entered.

## Dependências
Core Money/Percentage, history, and export services.
