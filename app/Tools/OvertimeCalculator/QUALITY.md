# Qualidade — Calculadora de Hora Extra

- [x] Natureza: cálculo trabalhista.
- [x] Dependência normativa: alta.
- [x] Resultado: estimativo e auditável.
- [x] Persistência: histórico autenticado pelo Core.
- [x] Exportação: CSV e impressão/PDF compartilhados.
- [x] Casos dourados cobrem cenário típico, fronteira, entrada inválida, arredondamento, não aplicação, transição normativa e regressão.
- [x] Hora normal, extras 50/100, hora noturna reduzida e DSR possuem regressões automatizadas.
