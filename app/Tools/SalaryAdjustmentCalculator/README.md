# Salary Adjustment Calculator

## Descrição
Projects a salary or wage adjustment from a user-entered percentage.

## Funcionalidades
Current pay, adjustment, and projected pay. Plus features are protected by central feature access.

## Experiência Essencial
Current pay, adjustment, and projected pay.

## Prazzu Plus
Plus features are protected by central feature access.

## Regras
The calculator is arithmetic only and does not infer contractual or statutory increases.

## Dependências
Core Money/Percentage.
