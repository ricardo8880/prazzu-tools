# EIN Format Validator

## Descrição
Validates the basic nine-digit format of U.S. Employer Identification Numbers. It does not verify IRS issuance.

## Funcionalidades
Single EIN validation. Plus adds batch EIN format validation.

## Experiência Essencial
Single EIN validation.

## Prazzu Plus
Plus adds batch EIN format validation.

## Regras
Format only: nine digits, nonzero; no IRS lookup.

## Dependências
Core tool access and standard Laravel validation.

## Histórico de versões
- 2.0.1: U.S. EIN-only scope and batch validation.
